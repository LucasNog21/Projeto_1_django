1- Criar ambiente virtual:
    python -m venv venv
    
    1- Ativar ambiente virtual:
        venv/Scripts/Activate

2- Instalar Django
    pip install Django

3- Criar projeto
    django-admin startproject nome_do_projeto

4- Criar app
    python manage.py startapp nome_do_app

    1- Adicionar app
        Entrar em projeto/settings.py e adicionar o nome do projeto em Installed_apps

    
5- Rodar servidor
    python manage.py runserver
    1- Debug runserver automático
        Criar launch-json com o runserver automático

6- Projeto/Urls
    from django.urls import include, path
    include urls do app

7- App/urls
    import funções de views
    Adicionar os caminhos de e funções: path(caminho, função)

8- views
    Função render para executar os templates em cada url

9- templates
    Local onde fica armazenado os templates(html) de cada url
    Adicionar templates não padrões na aba DIRS do projeto/settings: BASE_DIR / 'nome_da_pasta'
    Para evitar colisão de nomes colocar os templates dentro de outra pasta e referir os arquivos dentro das pastas indicadas - namespacing
