1- Criar ambiente virtual:
    python -m venv venv
    
    1- Ativar ambiente virtual:
        venv/Scripts/Activate

2- Instalar Django
    pip install Django

3- Criar projeto
    django-admin startproject nome_do_projeto

4- Criar app
    python manage.py startapp nome_do_app

    1- Adicionar app
        Entrar em projeto/settings.py e adicionar o nome do projeto em Installed_apps

    
5- Rodar servidor
    python manage.py runserver
    1- Debug runserver automático
        Criar launch-json com o runserver automático

9- templates
    Local onde fica armazenado os templates(html) de cada url
    Adicionar templates não padrões na aba DIRS do projeto/settings: BASE_DIR / 'nome_da_pasta'
    Para evitar colisão de nomes colocar os templates dentro de outra pasta e referir os arquivos dentro das pastas indicadas - namespacing

    1-exibição de variáveis no django
        {{alguma coisa}}
    2- Icones

    4- Adicionando templates em novas pastas:
        Sempre lembrar de atualizar o caminho nos views

    6- Ao lidar com arquivos estáticos, por convenção e utilização do framework:
    1- Criar arquivos
        -criar pasta static
            -criar pasta com o nome do app
                -criar pasta css (por exemplo)
    
        
    2- Configurar no project em settings
        -{% load static%} no django.html necessário
    
    3-Configurar novos caminhos static:
        STATICFILES_DIRS = [
            BASEDIR / 'caminho'
        ]


    4- Coletar arquivos estáticos 
        python manage.py collectstatic
            criar STATIC_ROOT no settings com o caminho
                (IMPORTANCIA de fazer namespacing para nao colidir nome entre eles )

    5- Herança templates
        {%block nome%} {%endblock nome} no template BASE_DIR
            {extends 'caminho/do/template/baseado/no/settings' } no arquivo diferente e englobar o block
